# Дорога до колледжа

Визуальная новелла про один день группы П-21 в селе Шамалган. Три героя (Адлан, Исмира, Сыпатай), много развилок и концовок, анимации и звуки.

Игра состоит из одного файла `index.html`, ничего устанавливать не нужно: открой его в браузере.

## Как выложить на GitHub Pages

1. Создай репозиторий на github.com (кнопка **New**), назови, например, `college-game`.
2. Нажми **Add file → Upload files** и перетащи сюда файлы `index.html` и `README.md` (не zip-архив, а сами файлы).
3. Нажми **Commit changes**.
4. Зайди в **Settings → Pages**. В разделе Source выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
5. Через минуту-две игра откроется по адресу `https://ТВОЙ-НИК.github.io/college-game/`.

# Игры нашей группы

Каталог автоматически показывает папки, добавленные в `games`.

## Как добавить игру

Создайте папку с уникальным названием латиницей:

```text
games/my-game/
├── index.html
├── style.css
└── script.js
```

Внутри `index.html` используйте относительные пути:

```html
<link rel="stylesheet" href="./style.css">
<script src="./script.js" defer></script>
```

Не изменяйте корневые `index.html`, `style.css` и `script.js`. После принятия Pull Request папка игры появится в каталоге автоматически.

## Публикация

В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main` и корневой папки проекта.

Каталог получает список папок через публичный GitHub API. Если сайт использует собственный домен, укажите владельца и название репозитория в объекте `CONFIG` в `script.js`.
